**The World in One Day — 18 November 2026.** A single-image summary of the world news of Wednesday 18 November 2026, typeset as an editorial front page: Trump heads to China for the first Trump-Xi-Putin summit, Ukraine cripples the Crimea Bridge, the U.S.-Iran clash flares in the Gulf, Nvidia's board shuts the door on founder Jensen Huang, the U.S. loses its measles-free status after 26 years, and Democrats seal the Senate 56-44. The Python program copies the poster to /output/entry.png, deterministically and offline.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

writes `out/entry.png` — the same bytes on every run, no network needed.
